# West I District SAPM Dashboard

Term 1, SY 2026-2027. Six schools: Bakilid, Cabancalan I, Maguikay, Tabok 1, Tabok 2, Tingub.

- `West1_SAPM_Dashboard.html`: self-contained dashboard (open in a browser)
- `West1_SAPM_data.json`: cleaned MPS rows and least-learned competencies extracted from the six SAPM files

## Deploy

Static site, no build step. On Vercel: Add New Project, import this repo, Framework Preset "Other", leave build and output settings empty. `index.html` is the dashboard.
